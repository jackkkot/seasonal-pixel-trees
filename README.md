# 季節像素樹

作品集用的像素風小玩具。畫面上先有一棵秋天的樹：點一下樹冠，葉子會帶著重力、一點旋轉和風落下；落完之後，可以讓它們重新長回來。

靈感來自一個有四棵像素樹的網站，春、夏、秋、冬各一棵，都能點擊落葉、再長回去。這個專案會往那個方向做。這次只先交出一棵能玩的樹。

這份說明是本週的計畫。第 5 天會再改成適合放上作品集的版本。

## 這是什麼

純前端的互動頁面，沒有帳號，也沒有後端。打開就能玩。

現在畫面上是秋天配色的一棵樹，用來把「點擊落葉、重新長回」這段手感先做對。春、夏、冬三棵是本週接著要補的。

## 怎麼玩

- 點樹冠，或按「搖落葉子」：葉子會落下。
- 按「重新長葉」，或在葉子落完後再點一次樹：葉子長回來。
- 葉子還在半空中時，按「重新長葉」也會把它們喚回來。

## 在本機執行

不用安裝套件，也不用建置。頁面就是 `index.html`、`styles.css`、`tree.js`。

用瀏覽器直接打開 `index.html` 即可。

若想用網址開啟（之後跟 GitHub Pages 的情況比較像），在專案目錄執行：

```bash
python3 -m http.server 8080
```

然後前往 http://localhost:8080 。

## 之後如何接上 GitHub Pages

這次還沒有開啟 GitHub Pages，留到本週第 5 天再部署。頁面都是靜態檔案，放在儲存庫根目錄，不需要建置指令。屆時的設定是：

1. 打開 GitHub 專案的 Settings → Pages
2. Source 選擇 Deploy from a branch
3. Branch 選擇 `main`，資料夾選擇 `/ (root)`
4. 儲存後，網站會出現在 https://jackkkot.github.io/seasonal-pixel-trees/

## 本週計畫

平日每天大約 2 到 3 小時。

- **第 1 天（這次 PR）**：一棵像素樹。點擊樹冠讓葉子落下（重力，加上一點旋轉和風），並能重新長回來。
- **第 2 天**：打磨重新長葉的動畫，以及點擊、搖落的手感。
- **第 3 到 4 天**：四棵樹，分別是春、夏、秋、冬。
- **第 5 天**：部署到 GitHub Pages，並把 README 改成適合放上作品集的版本。

## 技術選擇

- **純前端。** 這個玩具就是一張會動的畫，HTML、CSS、JavaScript 就夠。沒有框架，也沒有後端。雙擊 `index.html` 就能開，之後放到 GitHub Pages 也不用建置。
- **用 Canvas 畫像素。** 葉子要一顆顆掉下來、旋轉、被風帶著走，畫在 Canvas 上比較直接。程式會關掉影像平滑（image smoothing），畫面放大時用最近鄰，再加上 CSS 的 `image-rendering: pixelated`，邊緣才會是整齊的方塊。
- **先交出一段玩得到的版本。** 第一版只做一棵樹，以及葉子落下、葉子長回。這段順了，再在第 3 到 4 天加上四季。
