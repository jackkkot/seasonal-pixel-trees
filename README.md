# 秋樹

湖畔黃昏的一棵秋樹。打開頁面，雲慢慢移、樹冠輕輕搖，空中已經有幾片葉子在飄。樹幹是一整棵完整的樹，葉子落光之後枝椏還在。

每點一次樹冠，只會再落下一部分葉子。多點幾次，樹冠才會慢慢變薄，直到枝頭空了。空了之後可以再讓葉子長回來。這一頁只有秋天。

## 怎麼玩

- 點樹冠，或按「搖落葉子」：再落下一些還掛著的葉子。葉子會先後離開，帶著重力、風和旋轉，然後停在草地上。
- 按「重新長葉」：把已經離開的葉子喚回來。葉子全部落完後，再點一次樹也一樣。
- 葉子還在半空中時，按「重新長葉」也會把它們喚回來。

## 在本機執行

純前端，沒有框架，也沒有建置。檔案是 `index.html`、`styles.css`、`tree.js`，畫面在 `assets/`。

用瀏覽器直接打開 `index.html` 即可。若圖片因為瀏覽器擋住本地檔案而沒有出現，在專案目錄執行：

```bash
python3 -m http.server 8080
```

然後前往 http://localhost:8080 。

若要重切葉子，執行 `python3 tools/extract_leaves.py`。原畫和遮罩在 `assets/source/`。

GitHub Pages 從這個儲存庫的根目錄發布。合併到 `main` 之後，網站會更新在 https://jackkkot.github.io/seasonal-pixel-trees/ 。
